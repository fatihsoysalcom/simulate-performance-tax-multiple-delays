945ms Performance Tax Simulation

This example demonstrates how multiple small delays can accumulate, creating a significant "performance tax" for users. We'll simulate loading several components sequentially and then in parallel to see the difference in total perceived load time.

Scenario 1: Sequential Loading (High Tax)

Imagine a page loading components one after another. Each component has a small, inherent delay, adding to the overall wait time.

Task A: 200ms
Task B: 150ms
Task C: 300ms
Task D: 250ms

Scenario 2: Parallel Loading (Reduced Tax)

Now, imagine some components can load simultaneously, significantly reducing the overall waiting time by overlapping their delays.

Task A: 200ms (parallel)
Task B: 150ms (parallel)
Task C: 300ms (parallel)
Task D: 250ms (parallel)
